# Verification Matrix

이 문서는 README/docs의 구현 주장과 실제 코드/테스트 위치를 빠르게 대조하기 위한 표입니다.

Status 값은 다음 의미로 사용합니다.

- `Verified`: 구현이 있고 현재 테스트 커버리지로 확인합니다.
- `Implemented`: 구현은 있으나 이 표에서 별도 end-to-end 검증으로 주장하지 않습니다.
- `Future Scope`: 후속 구현 또는 문서화 대상으로 남긴 범위입니다.
- `Mismatch Fixed`: 이번 문서 감사에서 기존 문구와 실제 구현 차이를 정리한 항목입니다.
- `Not Implemented`: 현재 코드에 구현되어 있지 않습니다.
